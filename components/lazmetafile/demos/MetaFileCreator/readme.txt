--------------------------------------------------------------------------------
Metafile Creator
--------------------------------------------------------------------------------

This application creates simple metafiles in the .emf and .wmf format for 
testing.

In the listbox, select the type of image that you want to create - the image
will be drawn on the Paintbox at the right. Clicking on the "Save" button
writes it as metafile to disk, depending on which one of the "emf" or "wmf"
boxes is checked, in .emf or .wmf format.

Although primarily being a Lazarus application, it can be used also under
Delphi. Since Delphi directly employs the Windows metafile functions, these 
files can be considered as a reference for the files written and displayed by 
the LazMetafile package.
